# amoCRM Read-only MCP

Приватный MCP-коннектор для анализа amoCRM в ChatGPT. Коннектор не содержит методов создания, изменения или удаления данных.

## Что умеет

- проверять подключённый аккаунт;
- читать воронки, этапы и пользователей;
- получать ограниченные выборки сделок;
- строить агрегированный обзор воронки;
- находить незакрытые и просроченные задачи;
- получать историю смены этапов одной сделки;
- работать с долгосрочным токеном amoCRM или автоматически обновляемой OAuth-парой токенов.

## Требования

- VPS с Docker и Docker Compose;
- собственная интеграция amoCRM;
- Secure MCP Tunnel, связанный с тем же аккаунтом/рабочим пространством ChatGPT.

## 1. Настройка окружения

```bash
cp .env.example .env
chmod 600 .env
nano .env
```

Заполните значения локально на сервере. Никогда не отправляйте секретный ключ, код авторизации или токены в чат.

`AMO_BASE_URL` — адрес вида `https://company.amocrm.ru`.

Для одного аккаунта рекомендуется `AMO_LONG_LIVED_TOKEN`: создайте долгосрочный токен на вкладке «Ключи и доступы» и вставьте его только в `.env` на сервере. Поля `AMO_CLIENT_ID`, `AMO_CLIENT_SECRET` и `AMO_REDIRECT_URI` при этом не нужны.

## 2. Сборка и авторизация

```bash
docker compose build
```

При использовании долгосрочного токена дополнительная команда авторизации не нужна.

Для OAuth-режима вместо `AMO_LONG_LIVED_TOKEN` заполните `AMO_CLIENT_ID`, `AMO_CLIENT_SECRET` и `AMO_REDIRECT_URI`, затем выполните:

```bash
docker compose run --rm connector node dist/src/authorize.js
```

Вставьте одноразовый код непосредственно в терминал сервера. Токены сохраняются в закрытом Docker volume и автоматически обновляются.

## 3. Запуск и проверка

```bash
docker compose up -d
curl --fail http://127.0.0.1:3000/health
docker compose logs --tail=50 connector
```

Ожидаемый health-ответ:

```json
{"ok":true,"service":"amocrm-readonly-mcp"}
```

MCP endpoint: `http://127.0.0.1:3000/mcp`.

## 4. Подключение Secure MCP Tunnel

Создайте Tunnel в настройках OpenAI Platform, свяжите его с нужным ChatGPT workspace и запустите официальный `tunnel-client` на этом же VPS. Целевой локальный endpoint — `http://127.0.0.1:3000/mcp`.

В ChatGPT откройте Plugins → Add custom MCP server → Tunnel, выберите созданный tunnel и добавьте сервер как личный плагин. Не используйте режим `No authentication` для публичного endpoint; данный проект рассчитан на приватный Tunnel.

## Инструменты MCP

| Инструмент | Назначение |
|---|---|
| `get_account` | Проверка аккаунта и настроек |
| `list_pipelines` | Воронки и этапы |
| `list_users` | Сопоставление менеджеров и ID |
| `list_leads` | Ограниченная выборка сделок без телефонов и email |
| `get_lead` | Карточка одной сделки и ID связанных сущностей |
| `crm_overview` | Агрегаты по воронке и зависшим сделкам |
| `list_tasks` | Незавершённые, просроченные или связанные задачи |
| `lead_stage_history` | История переходов сделки между этапами |

## Безопасность

- MCP слушает только loopback-интерфейс VPS через Docker mapping.
- В amoCRM выполняются только `GET /api/v4/*`; POST используется только в необязательном OAuth-режиме для обмена и обновления токенов.
- В логах не печатаются секреты и токены.
- Контейнер работает без root, без Linux capabilities и с read-only filesystem.
- Телефоны и email контактов намеренно не запрашиваются.
